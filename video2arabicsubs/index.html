التثبيت السريع

اختر الحزمة المناسبة لمنصتك وثبّت Video2ArabicSubs

🐧

لينكس (Debian / Ubuntu)

المستودع الرسمي عبر APT

echo "deb [trusted=yes] https://ragaeidos.website/video2arabicsubs/ stable main" \ | sudo tee /etc/apt/sources.list.d/v2as.list
sudo apt update
sudo apt install v2as
جميع الإصدارات

بعد التثبيت: v2as (سطح المكتب) · v2as --web (تطبيق ويب) · v2as --lang en (إنجليزي).

💾
